# Каталог шоурума EUROSTOCK MOSCOW — Telegram Mini App

Канал @eurostockmoscowshop → бот читает посты → каталог на GitHub Pages → открывается в Telegram как Mini App.
Сервер не нужен: всё работает на бесплатных GitHub Actions + GitHub Pages.

## Как это работает
- Раз в 10 минут GitHub Actions запускает `bot/sync.js`: забирает новые посты и правки из канала (Bot API `getUpdates`),
  разбирает текст (бренд из хэштега, цена, размеры, состав), скачивает фото и видео в оригинальном качестве,
  пересобирает витрину `docs/index.html` и публикует.
- Зачёркнутый в посте размер = продан (перечёркивается в карточке, исчезает из фильтров). Все размеры зачёркнуты или
  в посте дописано «ПРОДАНО» — товар уходит с витрины. Сняли зачёркивание — вернулся.
- `#мужскаяодежда` (или слово «мужской/мужская» в тексте) — раздел «Мужское».
- Ручные правки хранятся в `curation.json` (главное фото, названия, скрытые товары) — их пишет бот по командам.

## Установка (один раз, ~15 минут)

### 1. Бот
1. В Telegram откройте **@BotFather** → `/newbot` → имя (например, «EUROSTOCK Каталог») и username (например, `eurostockshop_bot`).
2. Скопируйте токен вида `123456789:AAH...` — он понадобится на шаге 3.
3. Добавьте бота **администратором канала** @eurostockmoscowshop (достаточно права «Публикация сообщений»; без прав админа бот не видит посты канала).
4. Напишите боту `/start` в личку — он ответит вашим числовым id (пока вы не в списке админов). Запишите его.

### 2. Репозиторий на GitHub
1. Создайте аккаунт на github.com (если нет) и **публичный** репозиторий, например `eurostock-catalog` (публичный — чтобы Actions и Pages были бесплатными без лимитов).
2. Загрузите в него содержимое этого архива (Add file → Upload files, перетащить все папки; или через GitHub Desktop / git).
   Папки: `.github`, `bot`, `lib`, `data`, `docs`, файлы `curation.json`, `package.json`, `README.md`, `.gitignore`.
3. **Settings → Pages**: Source — «Deploy from a branch», Branch — `main`, папка — `/docs`. Сохранить.
   Через 1–2 минуты каталог откроется по адресу `https://<ваш-логин>.github.io/eurostock-catalog/`.

### 3. Секреты
**Settings → Secrets and variables → Actions → New repository secret:**
- `BOT_TOKEN` — токен из BotFather
- `ADMIN_IDS` — ваш id из шага 1.4 (несколько — через запятую)

Во вкладке **Variables** можно задать `CHANNEL` (по умолчанию `@eurostockmoscowshop`).

### 4. Запуск
**Actions → «Синхронизация каталога с каналом» → Run workflow.** Дальше он запускается сам каждые 10 минут.
Проверка: опубликуйте в канале тестовый пост с ценой — через 10–15 минут он появится в каталоге.

### 5. Кнопка в Telegram
1. @BotFather → `/mybots` → ваш бот → **Bot Settings → Menu Button** → укажите адрес каталога из шага 2.3 и подпись «Каталог».
2. Ссылка для закреплённого поста в канале: `https://t.me/<username_бота>?startapp` — открывает каталог.
   Ссылка на конкретный товар: `https://t.me/<username_бота>?startapp=p8326` (8326 — номер поста).

## Управление каталогом (личные сообщения боту)
Самый простой способ — переслать боту пост из канала и подписать:
- `продано` — снять товар с витрины
- `продано M L` — проданы размеры M и L
- `в наличии` / `в наличии M` — вернуть
- `мужское` — перенести в «Мужское»
- `фото 2` — сделать второе фото главным
- любой другой текст — станет названием товара

Команды по номеру поста: `/sold 8326`, `/sold 8326 M`, `/unsold 8326 M`, `/hide 8326`, `/show 8326`,
`/title 8326 Жакет из замши`, `/men 8326`, `/photo 8326 2`, `/status 8326`, `/help`.

Изменения попадают на витрину при следующем запуске (до 10 минут).

## Формат поста, который бот понимает лучше всего
```
Пуховик #MassimoDutti
Состав: пух 80%, перо 20%
Размер: XS, S, M
▪️24900₽ вместо 29900₽
Записаться на примерку
#мужскаяодежда@eurostockmoscowshop   ← только для мужских вещей
```
Первое слово строки с хэштегом бренда — название. Зачёркивайте проданный размер прямо в посте.

## Структура
- `bot/sync.js` — синхронизация и команды
- `lib/parser.js` — разбор текста поста в карточку
- `lib/build.js`, `lib/index.template.html` — сборка витрины
- `data/state.json` — все посты канала (тексты, зачёркивания, файлы медиа)
- `curation.json` — ручные правки
- `docs/` — готовый сайт (index.html, img/, video/)

Локально: `node bot/sync.js --build` — пересобрать витрину без обращения к Telegram.
